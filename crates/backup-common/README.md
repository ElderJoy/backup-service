# backup-common

Shared library crate used by both `backup-service` and `backup-worker`. Contains code that must be identical across binaries — protobuf types, AMQP topology, FFI bindings, and telemetry setup.

## Modules

### `proto` (generated)

gRPC types generated by `tonic-build` from [`proto/backup.proto`](../../proto/backup.proto). Provides the `BackupProcessor` service definition (`UpdateStatus`, `ReportResult`) and message types (`StatusUpdate`, `ProcessingResult`, `Ack`).

Built automatically by `build.rs` — no manual codegen step needed.

### `worker`

RabbitMQ infrastructure for the backup job pipeline:

- **`BackupJob`** — serializable message struct (backup ID, tenant ID, source path, encryption flag).
- **`connect_rabbitmq`** — connects to AMQP, declares durable exchange (`backup_events`), queue (`backup_jobs`), and binding.
- **`publish_job`** / **`create_channel`** — helpers used by the API to enqueue work.

### `ffi`

Safe Rust wrapper around a C Shannon entropy calculator (`ffi/c_src/entropy.c`), compiled via the `cc` crate in `build.rs`.

- **`shannon_entropy(data: &[u8]) -> f64`** — returns 0.0 (uniform) to 8.0 (random).
- **`EntropyLevel`** — classifies entropy into `Low`, `Normal`, `High`, `VeryHigh`. Values above 7.5 are flagged as suspicious (potential ransomware / encrypted content).

The C source is intentional — it demonstrates FFI, `unsafe` blocks, and `cc` build integration.

### `telemetry`

Shared observability initialization for both binaries:

- Configures `tracing-subscriber` with `EnvFilter` (respects `RUST_LOG`).
- When `OTEL_EXPORTER_OTLP_ENDPOINT` is set, exports distributed traces to Jaeger via OTLP/gRPC.
- Gracefully degrades to stdout-only tracing when Jaeger is unavailable.
- `shutdown_telemetry()` flushes pending spans on exit.

## Build Script (`build.rs`)

1. Compiles `src/ffi/c_src/entropy.c` → `libentropy.a` (static link).
2. Compiles `proto/backup.proto` → Rust gRPC types via `tonic-build`.

Requires `protoc` to be installed (see root README for setup).
